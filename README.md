# Projet SAS d'Analyse de Données

## Description

Ce projet utilise **SAS Visual Analytics** pour analyser les données d'une entreprise fictive, **Insight Toy Company**, produisant des jouets high-tech. Le projet inclut des rapports, des visualisations, des analyses géographiques et des modèles de machine learning. Les données comprennent des informations sur les clients, les ventes, et l'efficacité des usines à travers plusieurs années.

## Objectifs du projet

- Analyser les **ventes des produits** et la **satisfaction des clients**.
- Créer des **visualisations** interactives avec SAS Visual Analytics.
- Utiliser les **modèles de machine learning** pour des prévisions sur les ventes et la satisfaction.

## Fichiers inclus

- **rapport_SAS.pdf** : Document décrivant le projet et les méthodologies utilisées.
- **Start_SSB_V4L_DV_ML_V12.pdf** : Tutoriel pour l'utilisation de SAS Viya et de SAS Visual Analytics.
- **PVA.pdf** : Rapport contenant l'analyse des données et des modèles.
- **dataset.csv** : Données du modele  utilisées pour l'analyse.calcule du ROI

## Instructions

1. Ouvrir le fichier **dataset.csv** dans **SAS Visual Analytics**.
2. Créer un rapport avec des graphiques et des analyses basées sur les variables telles que **Product Sale**, **Customer Satisfaction**, et **Facility Efficiency**.
3. Explorer les **modèles de machine learning** pour les prévisions.
